# ⛅ Weather App

A simple **Weather App** built using **HTML, CSS, and JavaScript**.  
It fetches real-time weather data from an API and displays current conditions such as **temperature, humidity, wind speed, and weather description**.

---

## 🚀 Features
- Search weather by **city name**
- Displays:
  - 🌡️ Temperature  
  - 💧 Humidity  
  - 🌬️ Wind speed  
  - 🌥️ Weather condition + icon
- Responsive design (works on desktop & mobile)
- Error handling for invalid city names

---

## 🛠️ Technologies Used
- **HTML5** – page structure  
- **CSS3** – styling & responsive layout  
- **JavaScript (Vanilla JS)** – API fetching & DOM manipulation  
- **[OpenWeatherMap API](https://openweathermap.org/api)** – real-time weather data
